# 📊 Screen Time Analytics Dashboard

An interactive data dashboard built with **Dash (Plotly)** and **PostgreSQL**, designed to analyze children's average screen time across various filters like day type, gender, and age.

> This is part of my personal portfolio to demonstrate full-stack data visualization skills using Python, Dash, and a relational database.

---

## 🚀 Features

- 📅 Filter by **Day Type** (Weekday / Weekend)
- ⚥ Filter by **Gender**
- 👶 Filter by **Age Group**
- 📈 Interactive bar chart showing average screen time
- 📊 Live **summary cards** with key insights
- 🔁 **Reset filters** easily
- 📤 Export filtered data to **CSV**

---

## 🧰 Tech Stack

- **Python**
- **Dash (Plotly)** for frontend visualizations
- **PostgreSQL** for data storage
- **SQLAlchemy** for Python ↔️ SQL integration
- **Pandas** for data manipulation
